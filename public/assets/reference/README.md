## Recommended export

- Format: **PNG** (or WebP). Roughly **2400 px wide**, 2x pixel density.
- Aspect ratio near **1200 : 620** crops cleanly in the browser frame; other
  ratios are fine (they cover from the top).
- Crop out any personally identifiable operator data if these are shared publicly.

Until you add them, `SmartShot` renders an on-brand animated mock so the layout
is never broken.
